# Tic Tac Toe - Premium Edition

A modern, feature-rich Tic Tac Toe game with premium UI and smart AI.

## 🎮 Features

### Game Modes
- **Player vs Player** - Play against a friend locally
- **Player vs AI** - Challenge the computer opponent

### AI Difficulty Levels
- **Easy** - Random moves, perfect for beginners
- **Medium** - Mix of smart and random moves (50/50)
- **Hard** - Unbeatable AI using Minimax algorithm

### Premium Features
- ✨ Modern neon-themed UI with gradient backgrounds
- 🎨 Glowing X and O symbols
- 🎉 Particle effects on win
- 🔊 Procedural sound effects (click, win, draw)
- 📊 Score tracking across games
- 🏆 Animated winning line
- 🖱️ Smooth button hover animations
- ⚙️ Settings menu with sound toggle

## 🚀 Requirements

- Python 3.x
- Pygame library

## 📦 Installation

```bash
pip install pygame
```

## ▶️ How to Play

1. Run the game:
   ```bash
   python Tic-Tac-Toe-Premium.py
   ```

2. From the main menu:
   - Click "Play Game" to start
   - Choose your game mode (PvP or PvAI)
   - If playing vs AI, select difficulty in Settings

3. Game controls:
   - Click on any empty square to place your mark
   - Player X always goes first
   - First to get 3 in a row wins!

4. After game over:
   - "Play Again" - Restart with same settings
   - "Main Menu" - Return to main menu

## 🎯 Tips

- In Hard mode, the AI is unbeatable - best you can do is force a draw!
- Try Medium difficulty for a balanced challenge
- Use the score tracker to keep track of your wins

## 🛠️ Technical Details

- **Resolution**: 800x900 pixels
- **Game Board**: 600x600 pixels (centered)
- **Frame Rate**: 60 FPS
- **AI Algorithm**: Minimax with depth optimization
- **Sound**: Procedurally generated using pygame.mixer
